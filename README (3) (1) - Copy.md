## 🔗 Get a Live Shareable Link (in 60 seconds)

You want a URL like `sakhivijay.com` that you can drop in your Instagram bio, LinkedIn headline, email signature, resume, anywhere. Here are the three best options, fastest first:

### Option 1 — Netlify Drop · FREE, 60 seconds (recommended start)

1. Go to **https://app.netlify.com/drop**
2. Drag the entire portfolio folder onto the page
3. You instantly get a URL like `https://random-words-12345.netlify.app`
4. **Rename it:** Site settings → Change site name → type `sakhivijay`
5. Final URL: **`https://sakhivijay.netlify.app`** ✅

This URL is permanent, free, and ready to share. You can update the site anytime by dragging a new folder.

### Option 2 — Vercel · FREE (also great)

1. Go to **https://vercel.com/new**
2. Either drag the folder or push to a GitHub repo and connect
3. You get **`https://sakhivijay.vercel.app`** automatically

### Option 3 — Custom Domain (₹1,000–2,000/year)

For the most professional link, buy a domain and point it at Netlify/Vercel:

**Top picks (check availability on namecheap.com or godaddy.com):**
- **`sakhivijay.com`** — classic, owns your name ⭐ recommended
- `sakhi.studio` — agency vibe
- `sakhivijay.in` — India-specific, often cheaper
- `bysakhi.com` — personal-brand feel

In Netlify/Vercel settings, add your custom domain and follow the DNS instructions. Done.
